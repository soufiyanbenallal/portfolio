System

Eight lines and two surfaces build every section on this page.

Line grammar

Each line type has one job. Nothing gets a border for decoration.

Rail

Frame edges at 1200px. Run the full page and never break.

Seam + node

Top of every section. Full-bleed, fades past the rails, with a node at each crossing.

1.0
Spine

Splits the chapter label from content at 232px, same x in every chapter.

Cell

Shared 1px edges from a gap. Cards are carved from the grid, never floated on it.

Dash

Subdivision inside a cell, step boundaries, thresholds.

Fade

Soft split between peers, like the logo row, where a hard line would shout.

Beam

One accent pulse on one seam. The only thing that moves.

Hatch

45° lines for space that is off-limits: page margins, bands between chapters, the future on a chart, a danger zone.

Dots

A 16px dot field marks a canvas where a live object sits, like a chart or a diff.
